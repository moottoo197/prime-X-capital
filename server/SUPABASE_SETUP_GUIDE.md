# Complete Supabase Integration Guide for Alphavest

This guide details how **Supabase** connects to the Alphavest platform across **Authentication**, **PostgreSQL Database**, and **Storage**.

---

## 1. Credentials Required from Supabase Dashboard

Go to [https://supabase.com/dashboard](https://supabase.com/dashboard) and open your project.

1. Navigate to **Project Settings** > **API**:
   - **Project URL**: `https://<project-ref>.supabase.co`
   - **anon (public)** key: Used for client/public operations
   - **service_role (secret)** key: Used by your backend server to manage users and access storage buckets

2. Navigate to **Project Settings** > **Database**:
   - **Connection string** (URI format, Mode: Transaction or Session on port 5432 or 6543):
     `postgresql://postgres:[YOUR-PASSWORD]@db.<project-ref>.supabase.co:5432/postgres`

---

## 2. Environment Variables (`.env`)

Add the following to your `.env` file:

```env
# Supabase API & Project
SUPABASE_URL=https://<your-project-ref>.supabase.co
SUPABASE_ANON_KEY=eyJhbGciOi...
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOi...

# Supabase PostgreSQL Database Direct Connection
DATABASE_URL=postgresql://postgres:[YOUR-PASSWORD]@db.<your-project-ref>.supabase.co:5432/postgres?sslmode=require

# Storage Buckets
STORAGE_BUCKET_KYC=kyc-documents
STORAGE_BUCKET_PRIVATE=private-user-files
STORAGE_BUCKET_MARKETING=marketing-assets
```

---

## 3. Setting Up Supabase Database (PostgreSQL)

1. In your Supabase dashboard, go to the **SQL Editor**.
2. Open `/database/schema.sql` from this codebase and execute it.
3. This creates all necessary tables:
   - `profiles` (User records, role, KYC tier status, referral codes)
   - `wallet_balances` (Funding, Exchange, and Trading wallets per asset)
   - `ledger_entries` (Double-entry accounting log)
   - `kyc_submissions` (ID verification submissions and Supabase Storage paths)
   - `deposits` & `withdrawals`
   - `orders` & `positions`
   - `copy_trading_plans` & `trading_signals`
   - `system_settings`

---

## 4. Setting Up Supabase Storage

1. In your Supabase dashboard, go to **Storage** > **Buckets**.
2. Create the following buckets:
   - `kyc-documents` (Private bucket for passport/ID uploads)
   - `private-user-files` (Private bucket for payment proofs/receipts)
   - `marketing-assets` (Public bucket for banners, icons, badges)
3. For `kyc-documents`, set it to **Private** so that documents can only be accessed via secure signed URLs generated by the server.

---

## 5. Setting Up Supabase Authentication

1. In your Supabase dashboard, go to **Authentication** > **Providers** > **Email**.
2. Ensure **Email provider** is **Enabled**.
3. Under **Confirm email**:
   - For automatic signup and instant login: Disable "Confirm email" (or let the backend admin API create auto-confirmed accounts).
4. Configure initial Super Admin accounts securely via Supabase Dashboard or `server/.env`:
   - Set strong unique passwords (`<CONFIGURE_STRONG_PASSWORD>`) outside version control.

## 6. How the Code Works

### A. Backend Architecture (`/supabase.ts`)
- **`supabaseAdmin`**: Uses `SUPABASE_SERVICE_ROLE_KEY` to administer user accounts and storage.
- **`supabasePublic`**: Uses `SUPABASE_ANON_KEY` for password sign-ins.
- **`pgPool`**: Uses `DATABASE_URL` with SSL connection pooling to execute direct SQL queries.
- **Storage Helpers**:
  - `uploadToStorage(bucket, path, buffer, mimeType)`
  - `getSignedUrl(bucket, path, expiresInSeconds)`

### B. API Routing (`/server.ts`)
- `POST /api/auth/register`: Creates user in Supabase Auth, adds record to Supabase `profiles` table, initializes funding/exchange/trading balances.
- `POST /api/auth/login`: Signs in via Supabase Auth, returns JWT access token and user role.
- `POST /api/kyc/upload`: Accepts base64 image data and uploads to Supabase Storage `kyc-documents` bucket.
- `POST /api/kyc/submit`: Records ID details and Storage paths into Supabase `kyc_submissions`.
- `GET /api/admin/kyc`: Compliance officers view all submissions with fresh Supabase Storage signed URLs.

### C. Frontend (`/htdocs/assets/js/app.js`)
- Document file inputs trigger `handleKYCFileUpload(side, event)` to upload directly to Supabase Storage.
- Admin view displays direct clickable links `[Front Doc ↗]`, `[Back Doc ↗]`, `[Selfie ↗]` to view high-resolution uploaded files.

## 7. How to Run

```bash
# 1. Install dependencies
npm install

# 2. Build frontend assets
npm run build

# 3. Start the server
npm start
```
The server will start on port `3000`.
